# MARS-Greatest-Common-Divisor
Program to find the greatest common divisor written in Assembly using the MARS simulator.

This program aims to find the Greatest Common Divisor (GCD) of two numbers using recursion. The program prompts the user to provide two non-negative integer inputs x and y, then prints out gcd(x, y). In addition to printing the final GCD, the program also displays the number of recursive calls made during the computation.

For example, gcd(7, 3) = 1, gcd(42, 14) = 14, gcd(5, 0) = 5, gcd(0, 7) = 7

Example Console Interaction:
Please input the first integer: -12
!!!Invalid, please enter a non-negative integer
Please input the first integer: 120
Please input the second integer: 45
gcd(120, 45) = 15
Number of recursive calls: 4
